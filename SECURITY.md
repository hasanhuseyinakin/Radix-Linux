# Security Policy

Radix Linux icin guvenlik destegi: desteklenen Beta/Main surumlerde yaklasik iki ay.

Alpha kanali deney icin; patch bekleme.

## Supported Versions

| Version   | Supported |
| --------- | --------- |
| 1.0 beta  | yes       |
| 0.9 beta  | yes       |
| 0.8 beta  | yes       |
| 0.7 beta  | yes       |
| 0.6 beta  | yes       |
| 0.5 beta  | yes       |
| <0.4 beta | no        |

## Reporting a Vulnerability

Guvenlik aciklarini public issue olarak acma.

1. [GitHub Security Advisory](https://github.com/VFL-DEEP/Radix-Linux/security/advisories/new) ac, veya
2. Releases sayfasindaki maintainer iletisimi uzerinden yaz.

Gonderirken surum/ISO, adimlar, etki ve varsa gecici cozumu ekle.

Gecerli raporlara 72 saat icinde donmeye calisiyoruz.

## Non-Security Bugs

Normal buglar icin [bug report sablonu](.github/ISSUE_TEMPLATE/bug_report.md).
